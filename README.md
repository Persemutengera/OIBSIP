# OIBSIP Cybersecurity Internship

This repository contains my Cybersecurity Internship projects completed through Oasis Infobyte (OIBSIP).

## 🔐 Projects

The internship covered practical cybersecurity activities, including:

- Network reconnaissance and scanning with Nmap
- Vulnerability scanning with Nikto
- Network traffic analysis using Wireshark
- SQL Injection testing using DVWA
- Basic port scanning with Python
- Firewall configuration and security testing
- Security assessment and documentation
  
## 🛠️ Tools & Technologies
- Kali Linux
- Nmap
- Nikto
- Wireshark
- Burp Suite
- DVWA
- Python
- UFW
- Apache
  
## 🎯 Objective

The project focused on developing practical skills in network security, vulnerability assessment, web application security, traffic analysis, and security reporting through controlled laboratory environments.

## ⚠️ Disclaimer

All security testing was performed in authorized, isolated lab environments for educational purposes only.
